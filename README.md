# Tinder Auto Login via Facebook

This project automates the login process to [Tinder.com](https://tinder.com) using Facebook credentials via Selenium WebDriver.

## 🔧 Features

- Automated login to Tinder via Facebook
- Geolocation spoofing using Chrome DevTools Protocol
- Accepts cookie and notification pop-ups
- Handles Facebook login pop-up windows
- Improved detection of “Continue as...” button

## 🚀 Requirements

- Python 3.x
- Chrome Browser
- ChromeDriver (matching your Chrome version)
- Environment variables:
  - `FB_EMAIL`: Your Facebook email
  - `FB_PASSWORD`: Your Facebook password
